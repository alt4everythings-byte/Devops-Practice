# Lab 1: Git Basics, Branching and Merging

## Objective
Create a simple user registration form, initialize Git, create a branch, merge changes, and push to GitHub.

## Steps
1. git init
2. git add index.html
3. git commit -m "Initial commit"
4. git branch update-form
5. git checkout update-form
6. Modify index.html
7. git commit -m "Added department field"
8. git checkout main
9. git merge update-form
10. git push origin main
